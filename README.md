# metodyNumeryczne
Tutaj będą wstawiane oraz aktualizowane pliki związane z wykonaniem projektu w ramach Metod Numerycznych. Autorami są Adrian Popielarczyk oraz Zuzanna Orzechowska z Akademii Nauk Stosowanych w Elblągu

Zestaw zdjęć użytych do wytrenowania modelu oraz spis użytych albumów muzycznych, znajduje się pod adresem: https://mega.nz/folder/fJhw2BCS#FrvGyc5slAyZJpo0bRuK7Q
